# 기록샘

교사가 과정중심평가 결과와 학생 관찰 사실을 바탕으로 교과 평어 및 행동특성 초안을 작성하고 검토할 수 있는 생활기록부 작성 지원 웹앱입니다.

## 현재 구현 범위

- 학급 진행 현황 대시보드
- 학생별 상·중·하 평가 수준 입력
- 평가 근거와 관찰 메모 기반 교과 평어 검토
- 바이트, 종결어미, 금지 내용 검수 표시
- 행동특성 관찰 기록 및 성장 중심 초안 생성
- 교사의 최종 확인 및 확정 흐름
- PC, 태블릿, 모바일 반응형 UI

현재 버전은 PRD의 1차 개발 흐름을 검증하기 위한 프론트엔드 MVP입니다. 데이터는 화면 시연용이며 실제 로그인, 영구 저장, 엑셀 처리, 외부 AI API 연결은 후속 개발 대상입니다.

## 실행

Node.js 22.13 이상과 pnpm 11 이상이 필요합니다.

```bash
pnpm install
pnpm dev
```

검증:

```bash
pnpm build
node --test tests/rendered-html.test.mjs
```

## 주요 파일

- `app/page.tsx`: 화면 및 상호작용
- `app/globals.css`: 반응형 디자인
- `docs/PRD.md`: 제품 요구사항
- `.openai/hosting.json`: Sites 배포 설정
