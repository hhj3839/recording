## 재현 방법

로컬의 무시된 실험실 계정 파일 또는 `LOAD_TEST_EMAIL`, `LOAD_TEST_PASSWORD` 환경 변수를 사용함. 자격증명은 출력하지 않음.

```bash
pnpm test:load-comments start
pnpm test:load-comments status
```

`preflight`는 AI를 호출하지 않고 활성 학생 25명, 모든 과목의 상·중·하 입력 완전성, 예상 학생-과목 결과 수, 최소 배치 호출 수와 잔여 월 한도를 확인함. `start`는 같은 검증을 통과한 뒤 실제 작업을 등록하며, `status`는 최근 작업의 완료·실패·배치·저장 건수와 소요 시간을 출력함.

2026-07-27 최신 실측은 형식 수치 목표를 통과했지만 표본에서 부자연스러운 `함.` 결합이 발견되어 최종 품질 통과로 보지 않음. 학생별 고정 슬롯과 제한 서술어 구조로 개선했으며 OpenAI 프로젝트 결제 한도 복구 후 재검증이 필요함.
