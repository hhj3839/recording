# 기록샘 교사 파일럿 운영안

**버전:** v1.0  
**기간:** 2주  
**대상:** 초등교사 3~5명, 학교 1~2곳의 비공개 테스트

## 목적

- 교과 평어와 행동특성 작성 시간이 기존 대비 50% 이상 줄어드는지 확인
- 생성 결과의 평가 수준 일치도와 수정 후 사용 가능 비율 측정
- 개인정보·권한·내보내기 흐름의 실제 학교 사용성 확인

## 사전 조건

- 테스트용 가명 학생 명단 또는 학교 내부 승인된 자료 사용
- 개인정보 처리방침과 이용약관 확인
- 교사별 계정과 독립 학급 생성
- 앱의 교사별 월 생성 차단은 사용하지 않음. OpenAI 프로젝트 결제 설정과 앱의 호출 수·추정 비용을 관찰하고 작업별 호출 상한·분당 속도 제한은 유지함.

## 진행 절차

1. 교사가 학생 명단과 평가계획을 등록함.
2. 학생별 평가 수준을 입력함.
3. 과목별로 25명 교과 평어를 생성하고 9개 과목을 순서대로 확인함.
4. 교사가 평어의 수준 일치, 사실성, 표현 자연스러움을 검토하고 수정함.
5. 학생별 특성 4~5가지를 입력하고 행동특성을 생성함.
6. 바이트·종결·금지어·중복 검수를 확인함.
7. 번호순 본문 복사 후 나이스 붙여넣기 형태를 확인함.
8. 작업 시간과 수정량을 기록하고 종료 설문을 작성함.

## 측정 항목

- 명단·평가계획 업로드 성공 여부
- 과목별 25명 및 9과목 전체 생성 완료 시간과 성공률
- 50~60자 교과 문장 형식 통과율
- 평가 수준 의미 일치 표본 30문장 중 적합 문장 비율
- 행동특성 500~600바이트 및 음·임 종결 통과율
- 교사가 수정 없이 사용한 비율과 평균 수정 글자 수
- 기존 방식 대비 작업 시간 절감률
- 만족도, 재사용 의향, 치명적 오류와 개인정보 문제

## 성공 기준

- 교과 평어 형식 통과율 95% 이상
- 평가 수준 의미 일치도 95% 이상
- 행동특성 형식 통과율 95% 이상
- 교사 수정 후 사용 가능 비율 80% 이상
- 작성 시간 50% 이상 단축
- 데이터 노출 및 무단 접근 사고 0건

## 현재 상태

- 실험실 계정과 25명·9과목 데이터 준비 완료
- 인증·권한·핵심 화면 브라우저 E2E 완료
- 실제 교사 모집, 학교 승인, 2주 사용과 설문 수집은 외부 참여자가 필요한 단계로 대기 중
