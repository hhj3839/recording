# 생성 작업 배치 중단과 재개 검증 · 2026-11-05

## 수정 전 재현

행동특성은 결과를 저장한 뒤 작업 진행 위치를 기록하기 전에 중단되면 같은 학생을 다시 생성한다. 격리 검사에서는 현재 본문이 첫 번째 응답에서 두 번째 응답으로 교체됐다. 완료된 이전 배치의 본문과 작업 ID는 유지됐다.

| 실행기와 중단 지점 | 대상 배치의 생성 호출 횟수 (최초 + 재개) | 재개 후 결과 |
| --- | --- | --- |
| 행동특성, AI 응답 후 본문 저장 직전 | 1 + 1 | 중단 시 기존 초안 유지. 재개에서 두 번째 응답 저장 |
| 행동특성, 본문 저장 직후·진행 위치 기록 전 | 1 + 1 | 같은 행에 두 번째 응답이 저장돼 첫 저장 본문 교체 |
| 행동특성, 진행 위치 기록 직후·후속 호출 전 | 1 + 0 | 첫 본문 보존, 다음 배치부터 처리 |
| 교과평어, 구성 문장 저장 후 합본 저장 직전 | 0 + 0 | 승인 풀 구성 문장을 재사용해 합본 저장 |
| 교과평어, 합본 저장 직후·진행 위치 기록 전 | 0 + 0 | 합본을 두 번 저장했으나 이 고정 표본의 본문은 동일 |
| 평어 풀, 후보 응답 후 승인 문장 저장 직전 | 1 + 1 | 기존 승인 문장은 보존, 재시도에서 받은 새 후보 저장 |
| 평어 풀, 목표 수량 저장 직후·진행 위치 기록 전 | 1 + 0 | 저장된 승인 후보로 목표 수량을 채워 추가 호출 없이 완료 |

각 경우 실제 실행기와 명시적 재개 POST를 호출했다. 지정한 경계에서 첫 실행의 진행을 멈추고 DB 역할의 메모리 상태를 유지한 채 잠금 만료를 모의했다. 재개 요청이 예약한 기존 작업의 서명된 실행 요청을 전달하고 완료 상태·진행 위치·성공/실패 수와 결과 내용을 검사했다. 행동특성은 호출마다 서로 다른 응답을 반환하도록 해 같은 키에 본문이 덮어써지는지 판별했다.

행동특성은 중단된 배치 전체를 다시 pending으로 잡는다. 평어 풀은 승인 문장 목록을 다시 읽으므로 위의 저장 후 결과는 이미 목표 수량에 도달한 경우에 해당한다. 교과평어는 기본 재개 경로에서 입력 근거와 일치하는 저장 문장을 재사용한다. 강제 재생성, 후보 풀 변경, 부분 저장 조합은 별도 검증 대상이다.

호출 수는 행동특성의 생성 함수 또는 평어 풀의 모의 AI HTTP 요청을 센 값이다. 실제 요금·서버리스 종료 시간·Supabase 트랜잭션·수정 이력 보관은 이 검사 범위 밖이다. 현재 본문의 교체까지 확인했으며, 이력에서 이전 본문을 복원할 수 있는지는 미검증이다.

재현 명령은 프로젝트 루트에서 다음과 같다.

```sh
node --test tests/job-resume.test.mjs tests/job-status-read-only.test.mjs tests/generation-save-failure.test.mjs
```

장애 사례 7개를 포함한 관련 검사 52개와 변경 테스트 파일 린트가 통과했다. 이번 변경은 검사와 문서에 한정한다. 후속 P1은 동일 작업·배치·학생의 저장 완료 여부를 판별해 본문을 재사용하는 것이다. AI 응답을 받은 뒤 어떤 결과도 저장되기 전에 중단된 경우에는 호출 결과를 회수하거나 재호출을 명시적으로 선택하는 별도 정책이 필요하다. 교사 파일럿의 실제 판정은 0/30문장으로 대기 중이다.

## 행동특성 수정 후 재검증

학생 본문·이전 본문 이력·작업별 배치/학생 저장 완료 표시를 같은 PostgreSQL 트랜잭션에서 기록한다. 재개는 현재 작업의 완료 표시가 있는 학생을 건너뛰고 해당 학생을 완료 수에 합산한다. 정상적인 후속 배치나 다른 작업은 각각의 입력으로 생성한다. 응답 유실 등 저장 성공 여부가 불명확하면 실행기는 호출을 반복하지 않고 중단하며, 기존 작업을 명시적으로 재개하면 커밋된 상태를 다시 읽는다.

| 행동특성 중단 지점 | 대상 학생 생성 호출(최초 + 재개) | 본문과 진행 상태 |
| --- | --- | --- |
| AI 응답 후 첫 저장 전 | 1 + 1 | 재개 전에는 이전 초안이 유지됨. 저장 성공 후 재시도의 응답을 반영 |
| 저장 커밋 후 진행 위치 기록 전 | 1 + 0 | 첫 저장 본문을 그대로 사용. 저장도 총 1회 |
| 진행 위치 기록 후 후속 실행 전 | 1 + 0 | 다음 배치만 실행. 완료된 이전 배치 본문 유지 |

같은 배치에 저장 완료 학생과 미완료 학생을 섞은 검사에서는 미완료 학생만 호출했고, 완료 이후 교사가 수정한 본문은 보존했다. 전체 관련 검사 53개, 기본 빌드와 테스트 217개, 타입·린트 검사를 통과했다. 생성 호출 수는 모의 생성 함수 기준이다.

로컬 PostgreSQL 17의 별도 합성 DB에 실제 스키마와 0024 마이그레이션을 적용해 tests/behavior-save-checkpoints.sql을 실행했다. 두 번째 학생의 유효성 검사 실패 시 본문·이력·표시가 함께 롤백됐고, 성공 후 응답 유실을 가정해 저장을 반복해도 교사가 수정·확정한 본문과 이력 건수는 유지됐다. 오래된 실행 잠금으로 저장하는 요청도 거부됐다. 임시 DB와 서버는 검증 후 정리했다.

배포 시에는 supabase/0024_behavior_save_checkpoints.sql을 실행기보다 먼저 적용해야 한다. 기존에 진행 중인 행동특성 작업은 구버전 실행기가 완료 표시 없이 쓴 자료가 있을 수 있으므로 전환 전에 종료 여부를 확인한다. 과거 본문만으로 어느 작업의 결과인지 추정해 표시를 채우지 않는다. 이번 수정의 검증 범위는 로컬이며 운영 적용은 별도 단계다.
