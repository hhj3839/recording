## 실제 AI 부하 테스트

초기 10명 배치에서는 첫 배치 1/10만 엄격 형식을 통과함. 구조화 출력을 도입하고 배치를 5명으로 줄인 후 생성된 새 결과 26건은 모두 영역 수, 50~60자, `함.` 종결 검사를 통과했으나 대량 JSON 완결성과 배치 성공률이 낮았음.

안정적으로 기록된 중간 지점에서 30건 중 8건 성공, 22건 실패로 성공률은 26.7%였음. 이후 이전 작업 실행이 겹치면서 작업 카운터와 저장 건수가 혼합되어 전체 225건 성공률은 신뢰할 수 없으므로 테스트를 중단함.

### 발견된 문제와 조치

- 60초 함수 제한으로 재시도 완료 전 종료 → 실행 제한을 300초로 확대
- 취소 상태가 실행 중 함수에 의해 덮어써짐 → 저장 전·완료 전 취소 상태 재확인
- 성공 건수만 사용량에 기록 → 실제 API 호출 시도마다 기록
- JSON 응답 잘림 → 추론 비활성화, 출력 한도 확대, JSON Schema Structured Outputs 적용
- 5명 배치의 복합 실패 → 배치를 3명으로 축소
- API 호출 누적 → 교사별 월 한도를 150회로 축소

## 평가 수준 의미 일치 표본

사회 교과에서 30문장을 평가 영역·수준·기준과 대조함.

- 직접 일치: 27문장
- 교사 확인 필요: 3문장
- 명백한 수준 불일치: 0문장
- 보수적 의미 일치율: 90%

교사 확인 필요 사례는 평가기준에 명시되지 않은 `자신 있게`, `의미를 파악함`, `모둠원과 협력하여`와 같은 태도·과정 표현이 추가된 경우임. 목표 95%에 미달하므로 실제 파일럿 전 의미 일치 표본을 추가하고 프롬프트를 더 제한해야 함.

## 결론

화면·권한·엄격 형식 검사는 작동하지만 25명 전 과목 전체 생성은 아직 운영 통과 상태가 아님. Structured Outputs와 현재 5명 배치 버전을 다음 달 호출 한도 초기화 후 5명·1과목 게이트 테스트로 먼저 검증하고, 성공률 95% 이상일 때만 225건 전체 테스트로 확대해야 함.

행동특성도 10명 배치에서 5명 배치로 낮춰 대량 응답 잘림과 단일 요청 실패 범위를 줄였으며, 25명 실제 생성 성공률은 별도로 측정해야 함.

운영 보안 스모크 테스트는 약한 회원가입 비밀번호, 누락되거나 잘못된 학교·학급 정보, 비로그인 민감 API 접근, 다른 학급 식별자 사용, 작업 실행 서명 위조와 삭제 확인 문구 우회를 자동 차단하는지 확인함.
