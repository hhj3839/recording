행동특성은 최대 5명 배치로 대량 응답 잘림과 단일 요청 실패 범위를 줄였음. 실패 학생은 실제 바이트와 검수 사유를 포함해 한 명씩 재조정하며, 470~580바이트 범위에서 나머지 검수를 통과한 결과는 폐기하지 않고 화면에 보존함. 2026-08-11 최신 5명 게이트는 4/5명 엄격 통과와 5/5명 검토 가능 결과 보존을 확인했으며, 25명 실제 생성 성공률은 별도로 측정해야 함.
