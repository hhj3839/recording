# 기록샘 교사 파일럿 실행 절차

## 목적과 범위

최소 3개 학급 또는 3명의 교사를 대상으로 수기 작성과 기록샘 사용 시간을 같은 기준으로 측정하여, 교과 평어·행동특성·학급 전체 작성 시간이 각각 50% 이상 단축되는지 확인함.

이 문서는 제품 화면이나 Supabase에 별도 측정 정보를 저장하지 않는 운영 절차임. 측정 기록에는 학생 이름, 학번, 관찰 원문, 생성 문장, 로그인 이메일을 포함하지 않음.

**현재 상태(2026-08-13):** 절차와 익명 측정표는 준비 완료됐으나 실제 교사 표본은 아직 0건임. 최소 3개 표본이 완료되기 전에는 시간 50% 단축과 수정 후 사용 가능률 80%를 달성으로 표시하지 않음.

참여 교사에게는 시작 전에 [교사용 빠른 시작](./TEACHER_QUICK_START.md)을 제공함.

## 시작 전 승인 게이트

- 파일럿 계정, 대상 교사 수, 학급 수, 학생 수, 과목 수와 측정 기간을 확정함.
- 실제 AI 호출 횟수와 예상 비용을 계산하고 운영자에게 별도 승인을 받음.
- 승인 전에는 생성 버튼을 누르거나 실제 AI E2E·부하 검사를 실행하지 않음.
- 운영 사용자 학급을 테스트 데이터로 사용하거나 수정하지 않음.
- 파일럿 중 데이터 삭제, Supabase 마이그레이션, 운영 설정 변경은 별도 승인 없이 수행하지 않음.
- 참여 교사가 측정 목적과 익명 집계 항목을 확인하고, 학생 개인정보나 생성 본문을 측정표에 옮기지 않기로 동의한 뒤 시작함.
- 행동특성의 생성·저장·화면 경고·파일럿 품질 집계는 모두 500~600B를 정상 범위로 사용함.

## 표본과 측정 단위

- 최소 표본: 서로 다른 3개 학급 또는 3명의 교사
- 권장 학급 규모: 학생 25명
- 교과 평어: 평가수준 입력 시작부터 25명 결과 검토·본문 복사 완료까지
- 행동특성: 관찰 사실 입력 시작부터 25명 결과 검토·본문 복사 완료까지
- 전체 시간: 교과 평어와 행동특성의 순수 작성 시간 합계
- 수기 기준선과 기록샘 측정은 같은 교사가 비슷한 규모·난이도의 자료로 수행함.
- 공식 저장 결과 감사의 익명 30문장 표본은 이름·학번·학생 ID 없이 `R001` 형식으로 제공함. 교사는 각 문장의 평가수준 의미 일치 여부와 입력 밖 사실 포함 여부를 판정하며, 자동 휴리스틱 경고만으로 목표 달성을 확정하지 않음.
- 표본 JSON의 `judgment.meaningMatch`를 `pass` 또는 `fail`, `judgment.unsupportedFact`를 `yes` 또는 `no`로 작성한 뒤 `pnpm audit:teacher-review <검토파일.json>`으로 완료 수와 두 비율을 집계함. 판정이 남은 행이 있으면 `complete: false`로 표시함.
- 오류 상태를 유지한 기존 실험실 학급에서는 `AUDIT_MODE=teacher-review`와 정확한 `AUDIT_CLASSROOM_ID`를 사용해 알려진 오류 교과 평어를 제외한 부분 표본만 만들 수 있음. 출력의 제외 건수와 `partialReview: true`를 함께 보관하고 225건 전체 감사 결과로 기록하지 않음.
- `AUDIT_OUTPUT_FILE=.local-reports/<파일명>.json`을 지정하면 익명 검토표를 Git 제외 로컬 폴더에 저장함. 다른 경로는 차단하며, 검토 완료 후에도 학생 이름이나 학번을 추가하지 않음.

## 측정 규칙

1. 시작 직전에 타이머를 시작하고 종료 조건을 충족한 직후 정지함.
2. 로그인 교육, 최초 학급 생성 교육, 의도적인 휴식, 네트워크 장애 대기는 별도 시간으로 기록하고 순수 작성 시간에서 제외함.
3. AI 결과를 교사가 수정한 시간은 기록샘 사용 시간에 포함함.
4. 생성 실패 후 재시도와 누락 결과 확인 시간도 기록샘 사용 시간에 포함함.
5. 수기 기준선과 기록샘 측정을 같은 날 연속으로 수행해 피로도 편향이 커지지 않도록 순서를 표본마다 교차함.
6. 학생별 문장이나 개인정보는 측정표에 복사하지 않고 건수와 시간만 기록함.

## 표본별 측정표

아래 표를 복사하여 표본마다 한 행을 작성함. `T01`, `C01`처럼 익명 코드를 사용함.

| 항목 | 기록 값 |

| 교사 코드 | T01 |

| 학생 수 | 25 |
| 과목 수 | 숫자 |
| 측정 순서 | 수기→기록샘 또는 기록샘→수기 |
| 교과 평어 수기 시간(분) | 숫자 |
| 교과 평어 기록샘 시간(분) | 숫자 |
| 행동특성 수기 시간(분) | 숫자 |
| 행동특성 기록샘 시간(분) | 숫자 |

## 계산식

- 교과 평어 단축률 = `(교과 평어 수기 시간 - 교과 평어 기록샘 시간) / 교과 평어 수기 시간 × 100`
- 행동특성 단축률 = `(행동특성 수기 시간 - 행동특성 기록샘 시간) / 행동특성 수기 시간 × 100`
- 전체 단축률 = `(수기 전체 시간 - 기록샘 전체 시간) / 수기 전체 시간 × 100`
- 수정 후 사용 가능률 = `(수정 없이 사용한 문장 수 + 수정 후 사용한 문장 수) / 생성 대상 문장 수 × 100`

각 단축률은 표본별로 먼저 계산하고 최소 3개 표본의 중앙값을 사용함. 평균값만으로 목표 달성을 판정하지 않음.

## 성공 판정

- 교과 평어 시간 단축률 중앙값 50% 이상
- 행동특성 시간 단축률 중앙값 50% 이상
- 전체 작성 시간 단축률 중앙값 50% 이상
- 수정 후 사용 가능률 80% 이상
- 입력하지 않은 사실 생성 비율 3% 이하
- 금지 내용 포함률 0%
- 학생 개인정보 외부 노출 및 무단 접근 사고 0건

표본이 3개 미만이면 수치는 참고 결과로만 기록하고 PRD 성공 지표를 완료 처리하지 않음. 한 항목이라도 목표에 미달하면 실패 원인과 수정 계획을 기록한 뒤 재검증함.

## 종료 후 처리

- 사용량 화면에서 파일럿 계정의 호출 수와 비용 추정치를 확인함.
- 측정 결과에는 익명 코드와 집계값만 남기고 학생 개인정보가 포함된 메모는 보관하지 않음.
- 파일럿 계정이나 학급 자료 삭제가 필요하면 삭제 범위를 확인하고 별도 승인을 받은 뒤 수행함.
- 결과를 `docs/VALIDATION_REPORT_2026-07-26.md`와 PRD 성공 지표에 반영하고 GitHub PR·CI·Vercel 배포 상태를 확인함.
- 각 표본의 원자료가 모두 채워진 뒤에만 집계하며, 미입력 값을 0으로 간주하거나 성공률을 추정하지 않음.
