# 기록샘 교사용 빠른 시작

**대상:** 비공개 교사 파일럿  
**예상 흐름:** 학급 준비 → 평가계획 → 평가수준 → 교과 평어 → 행동특성 → 복사

## 시작하기 전에

- 학생 자료를 입력할 권한과 학교 내부 절차를 먼저 확인합니다.
- 주민등록번호, 연락처, 주소, 건강정보, 보호자 정보 등 민감정보는 입력하지 않습니다.
- AI 결과는 초안입니다. 실제 평가·관찰 사실과 맞는지 교사가 최종 확인합니다.
- 한 학급은 같은 반의 1년 자료를 관리하는 데 사용할 수 있습니다. 다른 학기·다른 반·새 학년도 자료를 분리할 때만 다른 학급을 추가합니다.

## 1. 학급과 학생 준비

1. 로그인 후 대시보드에서 학교·학년·반·학년도·학기가 맞는지 확인합니다.
2. 학생 명단에서 엑셀이나 한글 표의 `번호 + 이름` 두 열을 복사해 붙여넣습니다.
3. 학생 순서와 인원이 맞는지 확인합니다.

## 2. 평가계획 저장

1. `평가계획 관리`를 엽니다.
2. 평가계획 표를 입력칸에 붙여넣습니다.
3. 표 형식이 맞지 않으면 `변환 프롬프트 복사`를 눌러 ChatGPT에서 표를 변환한 뒤 결과를 다시 붙여넣습니다. 이 과정은 기록샘의 유료 AI 사용량에 포함되지 않습니다.
4. 미리보기를 확인하고 저장합니다. 같은 과목 안에서 단원명이 겹치는 경우에는 내용을 구분할 수 있는 단원명을 사용합니다.

## 3. 평가수준 입력

1. `평가수준 입력`에서 과목을 선택합니다.
2. 학생별로 상·중·하를 입력하거나 `일괄 입력 도구`의 표 붙여넣기를 사용합니다.
3. 저장 시점을 확인한 뒤 다음 과목으로 이동합니다.

## 4. 교과 평어 생성·검토·복사

1. `교과 평어`에서 과목을 선택하고 `AI 평어 생성`을 누릅니다.
2. 기존 결과가 있으면 기본 선택인 비어 있는 학생만 생성을 사용합니다.
3. 빨간색 오류 버튼이 있는 학생만 상세 내용을 확인합니다. 정상 결과에는 경고가 표시되지 않습니다.
4. 필요한 문장만 직접 수정하거나 학생별 `다시 생성`, `선택한 부분 바꾸기`를 사용합니다.
5. `평어만 복사하기`를 눌러 번호순 본문을 복사한 뒤 나이스의 첫 번째 학생 칸에 붙여넣습니다.

교과 평어는 25명·1과목당 정상적으로는 5회, 오류 보완을 포함해 최대 20회의 AI 호출을 사용합니다. 한 과목을 마친 뒤 사용량을 확인하고 다음 과목을 진행하세요.

## 5. 행동특성 생성·검토·복사

1. `행동특성 작성`의 왼쪽 칸에 관찰한 내용을 문장·메모·키워드 중 편한 방식으로 씁니다.
2. 학생마다 서로 다른 특징을 4가지 이상 입력합니다. 학생 이름과 민감정보는 쓰지 않습니다.
3. `행동특성 생성`을 누르고 오른쪽 결과를 확인합니다.
4. 500B 미만 또는 600B 초과, 종결·금지어·반복·맞춤법 등의 빨간색 오류가 있는 학생만 확인합니다.
5. 필요하면 직접 수정하거나 `다시 생성`을 사용합니다.
6. `행동특성만 복사하기`를 눌러 번호순 본문을 복사합니다.

## 파일럿에서 기록할 것

- 수기 작성 시간과 기록샘 작성 시간
- 생성 대상, 수정 없이 사용, 수정 후 사용, 사용하지 않은 문장 수
- 입력하지 않은 사실 또는 금지 내용 발견 건수
- 재시도 횟수와 개인정보 없는 개선 의견

학생 이름·학번·관찰 원문·생성 문장은 파일럿 측정표에 복사하지 않습니다. 자세한 측정 방법은 [PILOT_RUNBOOK.md](./PILOT_RUNBOOK.md)를 따릅니다.

## 문제가 생기면

- 생성 버튼을 반복해서 누르지 말고 화면의 오류 문구와 발생 시각을 기록합니다.
- 다른 교사나 다른 학급의 자료가 보이면 즉시 사용을 중단합니다.
- 베타 문의는 GitHub Issues를 이용합니다: <https://github.com/hhj3839/recording/issues>
- 자료 삭제는 복구할 수 있으리라 가정하지 말고, 범위를 확인한 후에만 실행합니다.
