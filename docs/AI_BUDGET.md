# 기록샘 AI 운영 예산 정책

**적용 범위:** 비공개 교사 파일럿  
**기준일:** 2026-08-13

## 확정 기준

- 기본 모델: `gpt-5.4-mini`
- 자동 보완 모델을 별도로 사용하지 않고 최초 생성과 보완 모두 같은 저비용 모델 사용
- 교과 평어 평가영역 묶음당 호출 상한: 문장 풀 최초 생성·보완·중복 보완을 합쳐 최대 5회
- 교과 평어 기본 호출 수: 평가영역당 1회(한 요청 안에서 상·중·하 수준별 익명 문장 풀 생성)
- 교사별 월 AI 호출 한도: 150회
- 교사별 분당 호출 한도: 10회
- OpenAI 프로젝트 월 예산 시작값: USD 10
- 예산 70% 도달 시 사용량과 재시도율 검토
- 예산 90% 도달 시 신규 파일럿 계정 발급과 대량 생성을 일시 중단
- 예산 100% 도달 시 OpenAI Platform 프로젝트 한도로 추가 결제를 차단

## 산정 근거

GPT-5.4 mini의 공개 가격은 입력 100만 토큰당 USD 0.75, 캐시 입력 USD 0.075, 출력 USD 4.50임. 기본 생성과 형식 보완 모두 동일한 저비용 모델을 사용함. 앱은 실제 API 호출 시도 횟수와 함께 모델, 입력 토큰, 캐시 입력 토큰, 출력 토큰, 전체 토큰, 예상 비용을 기록함.

25명 교과 평어는 학생별로 직접 생성하지 않고 같은 평가영역·평가수준별 필요한 수량의 익명 문장 풀을 생성함. 오류가 없으면 호출 수는 학생 수가 아니라 평가영역 수와 같으며, 현재 9과목 25개 평가영역은 기본 약 25회임. 서버는 근거·수준·형식·중복을 통과한 후보만 학생에게 배정하고 성공 영역은 즉시 저장함. 후보가 부족하면 누락된 학생·영역만 최대 10개씩 보완하며, 한 평가영역 묶음의 전체 호출은 최대 5회임.

모든 평가영역이 상한까지 보완되면 월 150회 제한에 도달할 수 있으므로 서버는 작업 시작 전과 호출마다 남은 한도를 확인함. 파일럿에서는 과목별 실제 호출 수·후보 부족률·비용을 확인한 뒤 다음 과목을 진행함.

## 운영 확인

- 매주 OpenAI Platform 사용 금액과 앱의 `ai_usage_events` 호출 수를 대조함.
- 형식 재시도율이 20%를 넘으면 프롬프트·배치 크기를 우선 조정함.
- 한 과목 생성 후 사용량 화면에서 실제 호출 수와 남은 월 한도를 확인한 뒤 다음 과목을 진행함.
- 파일럿 종료 후 실제 교사당 비용을 바탕으로 월 예산과 호출 한도를 다시 산정함.
- OpenAI Platform의 프로젝트 월 예산·알림 설정은 서비스 운영자가 대시보드에서 별도로 적용해야 함.
- 225건 전체 부하 검사는 5명·25명 게이트 통과 후 `RUN_FULL_225_TEST=YES`를 명시한 경우에만 실행함.
- 행동특성 실제 검사는 `pnpm test:load-behaviors:preflight`로 비용 없이 준비 상태를 확인한 뒤 `RUN_BEHAVIOR_5_TEST=YES` 5명 게이트를 먼저 실행함. 25명 검사는 5명 통과 후 `RUN_BEHAVIOR_25_TEST=YES`일 때만 실행함.
