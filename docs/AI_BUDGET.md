# 기록샘 AI 운영 예산 정책

**적용 범위:** 비공개 교사 파일럿  
**기준일:** 2026-07-26

## 확정 기준

- 기본 모델: `gpt-5.4-mini`
- 자동 보완 모델을 별도로 사용하지 않고 기본 저비용 모델로 한 번만 재시도
- 교사별 월 AI 호출 한도: 150회
- 교사별 분당 호출 한도: 10회
- OpenAI 프로젝트 월 예산 시작값: USD 10
- 예산 70% 도달 시 사용량과 재시도율 검토
- 예산 90% 도달 시 신규 파일럿 계정 발급과 대량 생성을 일시 중단
- 예산 100% 도달 시 OpenAI Platform 프로젝트 한도로 추가 결제를 차단

## 산정 근거

GPT-5.4 mini의 공개 가격은 입력 100만 토큰당 USD 0.75, 캐시 입력 USD 0.075, 출력 USD 4.50임. 기본 생성과 형식 보완 모두 동일한 저비용 모델을 사용함. 앱은 실제 API 호출 시도 횟수와 함께 모델, 입력 토큰, 캐시 입력 토큰, 출력 토큰, 전체 토큰, 예상 비용을 기록함.

25명·9과목 교과 평어 전체 생성은 과목별 5명 배치 기준 최소 45회 호출이 필요함. 각 영역은 한 호출 안에서 길이가 다른 후보 2개를 받아 유효 문장을 선택하며, 실패 학생도 배치 단위로 한 번만 보완하므로 전 배치 재시도 시 최대 90회임. 교사별 150회는 전 과목 전체 생성 1회와 행동특성·일부 재생성을 수행하는 파일럿 상한임.

## 운영 확인

- 매주 OpenAI Platform 사용 금액과 앱의 `ai_usage_events` 호출 수를 대조함.
- 형식 재시도율이 20%를 넘으면 프롬프트·배치 크기를 우선 조정함.
- 파일럿 종료 후 실제 교사당 비용을 바탕으로 월 예산과 호출 한도를 다시 산정함.
- OpenAI Platform의 프로젝트 월 예산·알림 설정은 서비스 운영자가 대시보드에서 별도로 적용해야 함.
- 225건 전체 부하 검사는 5명·25명 게이트 통과 후 `RUN_FULL_225_TEST=YES`를 명시한 경우에만 실행함.
