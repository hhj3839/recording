# 기록샘 AI 운영 예산 정책

**적용 범위:** 비공개 교사 파일럿  
**기준일:** 2026-07-26

## 확정 기준

- 사용 모델: `gpt-5.6-terra`
- 교사별 월 AI 호출 한도: 150회
- 교사별 분당 호출 한도: 10회
- OpenAI 프로젝트 월 예산 시작값: USD 10
- 예산 70% 도달 시 사용량과 재시도율 검토
- 예산 90% 도달 시 신규 파일럿 계정 발급과 대량 생성을 일시 중단
- 예산 100% 도달 시 OpenAI Platform 프로젝트 한도로 추가 결제를 차단

## 산정 근거

GPT-5.6 Terra의 공개 가격은 입력 100만 토큰당 USD 2.50, 출력 100만 토큰당 USD 15.00임. 실제 비용은 평가계획 길이, 학생 수, 재시도 횟수에 따라 달라지므로 앱은 성공 건수가 아니라 실제 API 호출 시도 횟수를 기록함.

25명·9과목 교과 평어 전체 생성은 현재 배치 크기 기준 최소 45회 호출이 필요함. 교사별 150회는 한 달에 전체 생성 약 3회 또는 생성 1~2회와 행동특성·개별 재생성을 사용할 수 있는 파일럿 상한임.

## 운영 확인

- 매주 OpenAI Platform 사용 금액과 앱의 `ai_usage_events` 호출 수를 대조함.
- 형식 재시도율이 20%를 넘으면 프롬프트·배치 크기를 우선 조정함.
- 파일럿 종료 후 실제 교사당 비용을 바탕으로 월 예산과 호출 한도를 다시 산정함.
- OpenAI Platform의 프로젝트 월 예산·알림 설정은 서비스 운영자가 대시보드에서 별도로 적용해야 함.
